# License status

This project does not yet have a project-wide redistribution license. Do not infer one from the repository being publicly readable.

The BOINC host code is adapted from Bryan Little's AP26 OpenCL application, which in turn cites Jarosław Wróblewski's AP26 sample implementation. The [upstream AP27 repository](https://github.com/mfl0p/ap27) does not provide a license file. Wróblewski's [AP26 paper](https://www.math.uni.wroc.pl/~jwr/AP26/AP26v3.pdf) contains a copyleft notice for distributing the **document**; it does not clearly license reuse of the program source. Permission for redistribution and modification of the derived source needs to be clarified with the relevant rights holders before this project is published as an open-source release.

The BOINC and Vulkan libraries used to build or package the program have their own licenses. This file does not change those terms or grant rights to their code.
